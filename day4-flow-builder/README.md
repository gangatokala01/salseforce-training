##### Day 4 - Salesforce Flow Builder
## 1. What is Flow Builder?
Flow Builder is a Salesforce automation tool used to automate business processes without writing code.
It provides a drag-and-drop interface where users can create workflows, collect user input, update records, send emails, and perform automated actions.
Flow Builder helps organizations:
- Reduce manual work
- Improve productivity
- Minimize human errors
- Standardize business processes
- Save time using automation
It is one of the most important no-code automation tools in Salesforce.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

## 2. Types of Flows
Salesforce provides different types of flows for different business needs.
## A) Screen Flow
Screen Flow is an interactive flow that collects input from users through screens.
## Features:
- User-friendly forms
- Step-by-step screens
- Buttons, text fields, dropdowns
- Used for guided processes

### Example:
College Admission Form:
1. Student enters details
2. Flow validates information
3. Admission record is created
4. Confirmation message is shown

### Best Use Cases:
- Registration forms
- Survey forms
- Customer support forms
- Employee onboarding
## B) Record Triggered Flow

Record Triggered Flow runs automatically when a record is:
- Created
- Updated
- Deleted
No user interaction is required.

### Features:
- Fully automatic
- Runs in background
- Faster business automation
- Reduces repetitive work

### Example:
When a new student record is created:
- Send welcome email
- Update admission status
- Notify department automatically

### Best Use Cases:
- Auto notifications
- Status updates
- Approval automation
- Automatic calculations

# 6. Reflection - Why Automation Matters in Enterprise Systems

Automation is very important in enterprise systems because companies handle large amounts of data and processes daily. Manual work becomes slow, expensive, and error-prone.

Using automation:
- Businesses save time
- Employees become more productive
- Customer experience improves
- Work becomes standardized
- Errors are reduced
- Processes become scalable

No-code tools like Salesforce Flow Builder help even non-programmers automate business operations efficiently.

# ✍ Reflective Questions

## 1. Why do companies automate workflows?

Companies automate workflows to save time, reduce manual effort, improve productivity, and minimize errors.

## 2. What problems happen with manual processes?

Manual processes can cause:
- Human mistakes
- Delays
- Data inconsistency
- Increased workload
- Poor tracking

## 4. Why is no-code automation powerful?

No-code automation allows business users to automate workflows without programming knowledge. It reduces development time and makes automation accessible to everyone.

## 5. When should automation be avoided?

Automation should be avoided when:
- Human judgment is required
- Processes change frequently
- Very small/simple tasks do not need automation
- Incorrect automation may create risks
## 6. How does automation improve consistency and productivity?

Automation performs tasks the same way every time, reducing errors and ensuring consistency. Employees save time and can focus on more valuable work, improving productivity.
